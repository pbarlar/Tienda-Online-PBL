# Tienda Online PBL

Proyecto conjunto de Desarrollo Web en Entorno Servidor, Diseño de Interfaces Web y Despliegue de Aplicaciones Web.

## 🔗 Repositorio

El código fuente del proyecto se encuentra disponible en GitHub en la siguiente URL:
> **[https://github.com/pbarlar/Tienda-Online-PBL](https://github.com/pbarlar/Tienda-Online-PBL)**

## 📋 Descripción

Este proyecto consiste en una aplicación de comercio electrónico (Tienda Online) desarrollada con tecnologías web estándar. El objetivo es simular un entorno de tienda real con funcionalidades de autenticación y gestión simulada de usuarios.

## 🚀 Cómo acceder y ejecutar

Para visualizar y navegar por el proyecto, sigue estos pasos:

1. **Clonar o descargar:** Descarga el código fuente o clona este repositorio.
2. **Ejecutar:** 
   - Abre el archivo `src/index.html` en tu navegador web preferido.
   - Recomendamos usar una extensión como **Live Server** en VS Code para evitar problemas con rutas relativas o CORS.

## 🔐 Credenciales de Acceso

El sistema de login valida contra usuarios de prueba. Para acceder a las funcionalidades privadas de la tienda, utiliza la siguiente cuenta:

| Campo | Valor |
|-------|-------|
| **Usuario** | `emilys` |
| **Contraseña** | `emilyspass` |

> ℹ️ **Nota:** Las credenciales son verificadas utilizando la API de usuarios de `dummyjson.com`.

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica.
- **CSS3 / BEM**: Estilos y diseño responsivo.
- **JavaScript**: Lógica del cliente, manejo del DOM y peticiones a API (fetch).
